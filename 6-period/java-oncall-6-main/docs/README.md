# 기능 목록

## 입력 기능

- [x] 비상 근무를 배정할 월과 시작 요일 입력 `5,월`
    - [x] 입력한 월이 존재하지 않는 경우 예외 발생시키기
    - [x] 입력한 요일이 존재하지 않는 경우 예외 발생시키기
    - [x] 공백일 경우 예외 발생시키기
    - [x] 잘못된 입력 재입력 처리하기 `[ERROR] 유효하지 않은 입력 값입니다. 다시 입력해 주세요.`
- [x] 평일 비상 근무 순번대로 사원 닉네임 입력 `준팍,도밥,고니,수아,루루,글로,솔로스타,우코,슬링키,참새,도리`
    - [x] 공백일 경우 예외 발생시키기
    - [x] 잘못된 입력 재입력 처리하기 `[ERROR] 유효하지 않은 입력 값입니다. 다시 입력해 주세요.`
- [x] 휴일 비상 근무 순번대로 사원 닉네임 입력 `준팍,도밥,고니,수아,루루,글로,솔로스타,우코,슬링키,참새,도리`
    - [x] 공백일 경우 예외 발생시키기
    - [x] 잘못된 입력시 평일 비상 근무 순번부터 재입력 처리하기 `[ERROR] 유효하지 않은 입력 값입니다. 다시 입력해 주세요.`

## 비지니스 기능

- [x] 해당 월의 총 일수 등록
    - 매년 2월은 28일까지만 있다고 가정
- [x] 사원 등록
    - [x] 닉네임 글자 범위 최소 1 ~ 최대 5자
    - [x] 닉네임 중복 시 예외 발생
- [x] 비상근무표 생성
    - 근무자 범위
        - [x] 최소 5명 ~ 최대 35명
    - 근무자 규칙
        - [x] 평일 순번, 휴일(토요일, 일요일, 법정공휴일) 순번에 각각 1회 편성
        - [x] 연속 2일 근무 불가
            - 연속 2일 근무일 시, 다음 근무자와 순서 변경
            - 다음 근무자와 순서를 바꿔야 하는 경우, 앞의 날짜부터 순서 변경

## 출력 기능

- [x] 비상근무표 출력하기
    - 평일이면서 범정공휴일의 경우, 요일 뒤에 `(휴일)` 표기 `5월 5일 금(휴일) 루루`
- [x] 예외 메세지 출력
    - `[ERROR]` 로 시작할 것

휴일 비상 근무 순번대로 사원 닉네임을 입력하세요> 수아,루루,글로,솔로스타,우코,슬링키,참새,도리,준팍,도밥,고니

5월 1일 월 준팍
5월 2일 화 도밥
5월 3일 수 고니
5월 4일 목 수아
...```
