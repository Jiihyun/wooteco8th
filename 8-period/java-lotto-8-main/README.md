# java-lotto-precourse 기능 목록

## 입력 기능

- [] 로또 구입 금액 입력
    - [] 공백일 경우 예외 발생시키기
    - [] 숫자 아닐 경우 예외 발생시키기
    - [] 잘못된 입력 재입력 처리하기
- [] 당첨 번호 입력, 번호는 쉼표(,)를 기준
    - [] 공백일 경우 예외 발생시키기
    - [] 잘못된 형식일 경우 예외 발생시키기
    - [] 잘못된 입력 재입력 처리하기
- [] 보너스 번호 입력
    - [] 공백일 경우 예외 발생시키기
    - [] 숫자 아닐 경우 예외 발생시키기
    - [] 잘못된 입력 재입력 처리하기

## 비지니스 기능

- 로또 구매하기
    - [] 1,000 단위로 구매 가능, 아닐 경우 예외 처리
    - [] 최소 1장 ~ 최대 100장
    - 로또 번호 6개 생성하기
- 당첨 번호 및 보너스 번호 저장
    - [] 로또 번호 개수: 중복 없이 6개
    - [] 숫자 범위: 1 ~ 45
    - [] 당첨 번호 & 보너스 번호 중복시 예외 처리
- [] 당첨 로또 추첨하기
- [] 수익률 계산하기
    - 당첨 금액 / 구입 금액 * 100

## 출력 기능

- [] 발행 로또 수량 및 번호 출력
    - 로또 번호 오름차순
    - ```text
  8개를 구매했습니다.
  [8, 21, 23, 41, 42, 43]
  [3, 5, 11, 16, 32, 38]
  [7, 11, 16, 35, 36, 44]
  [1, 8, 11, 31, 41, 42]
  [13, 14, 16, 38, 42, 45]
  [7, 11, 30, 40, 42, 43]
  [2, 13, 22, 32, 38, 45]
  [1, 3, 5, 14, 22, 45]
    ```
- [] 당첨 내역 출력
    - 몇 개 일치하는지 개수, 금액, 보너스볼 일치 여부, 일치 개수
    - 수익률은 소수 둘쨰 자리에서 반올림
- [] 예외 메세지 출력
    - `[ERROR]` 로 시작할 것

## 실행 예시

자판기가 보유하고 있는 금액을 입력해 주세요.

```
