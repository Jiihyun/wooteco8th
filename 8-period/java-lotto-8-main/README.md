# java-lotto-precourse

## 📝️ 기능 목록

### ▪️ 입력 기능

- 로또 구입 금액 입력 받기
    - [x] 공백일 경우 예외를 발생시키기
    - [x] 숫자 형식이 아닐 경우 예외 발생시키기

- 당첨 번호 입력 받기
    - [x] 공백일 경우 예외를 발생시키기
    - [x] 지정된 입력 형식(쉼표 기준)이 아닐 경우 예외 발생시키기

- 보너스 번호 입력 받기
    - [x] 공백일 경우 예외를 발생시키기
    - [x] 숫자 형식이 아닐 경우 예외 발생시키기

### ▪️ 비지니스 기능

- 로또 발행하기
    - [x] 구입 금액만큼 로또 발행
    - 조건 미충족 시 예외를 반환한다.
        - [x] 구입 금액이 `1_000`원 단위이어야 한다.
    - [x] 무작위로 고유한 로또 번호 생성
    - 조건 미충족 시 예외를 반환한다.
        - [x] 로또 번호가 총 `6개`이어야 한다.
        - [x] 로또 번호 범위가 `1-45` 사이여야 한다.
        - [x] 로또 번호가 서로 중복되지 않아야 한다.

- 당첨 비교하기
    - [x] 당첨 번호와 보너스 번호가 중복되지 않아야 한다.
    - [x] 당첨 번호와 가지고 있는 로또 번호의 일치 개수 확인

- 수익률 계산하기
    - [] 당첨 금액 / 구입 금액 * 100

### ▪️ 출력 기능

- [x] 발행한 로또 수량 및 번호를 출력
    - [x] 로또 번호 오름차순 정렬
- [] 당첨 내역 출력
- [] 수익률 출력(소수점 둘째 자리에서 반올림)

- [] 예외 메세지 출력
    - `[ERROR]` 로 시작할 것
