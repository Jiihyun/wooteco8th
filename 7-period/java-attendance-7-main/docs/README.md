# 기능 목록

## 입력 기능

- [] 닉네임&출석 일시 파일 입력 `src/main/resources/attendances.csv`
- [x] 오늘 날짜와 함깨출석 프로그램 기능 명령어 입력
    - `오늘은 %d월 %d일 %s요일입니다. 기능을 선택해 주세요.`
    - [x] 공백일 경우 예외 발생시키기
    - [x] 존재하지 않는 명령어 예외 발생시키기 `[ERROR] 잘못된 형식을 입력하였습니다.`
- 출석 확인
    - [x] 닉네임 입력 `닉네임을 입력해 주세요.`
        - [x] 공백일 경우 예외 발생시키기
        - [] 존재하지 않는 닉네임 예외 발생시키기
    - [x] 등교 시간 입력 `등교 시간을 입력해 주세요.`
        - [x] 공백일 경우 예외 발생시키기
        - [] 잘못된 시간 형식 예외 발생시키기
- 출석 수정
    - [] 닉네임 입력 `출석을 수정하려는 크루의 닉네임을 입력해 주세요.`
        - [] 공백일 경우 예외 발생시키기
        - [] 존재하지 않는 닉네임 예외 발생시키기
    - [] 수정 날짜 입력 `수정하려는 날짜(일)를 입력해 주세요.`
        - [] 공백일 경우 예외 발생시키기
        - [] 숫자 아닌 경우 예외 발생시키기
    - [] 변경 시간 입력 `언제로 변경하겠습니까?`
        - [] 공백일 경우 예외 발생시키기
        - [] 잘못된 형식 예외 발생시키기
- 크루별 출석 기록 확인
    - [] 닉네임 입력 `닉네임을 입력해 주세요.`
        - [] 공백일 경우 예외 발생시키기
        - [] 존재하지 않는 닉네임 예외 발생시키기

## 비지니스 기능

- 출석 확인
    - [] 닉네임과 출석 시간을 가진 크루 출석 기록 저장하기
    - [] 한번 출석 후, 다시 출석할 경우 예외 반환 `[ERROR] 이미 출석을 확인하였습니다. 필요한 경우 수정 기능을 이용해 주세요.`
    - [] 등록되지 않은 닉네임을 입력한 경우 예외 반환 `[ERROR] 등록되지 않은 닉네임입니다.`
    - [] 주말 또는 공휴일인 경우 **오늘 날짜와 함께** 예외 반환 `[ERROR] 12월 14일 토요일은 등교일이 아닙니다.`
    - [] 등교 시간이 캠퍼스 운영 시간이 아닌 경우 예외 반환 `[ERROR] 캠퍼스 운영 시간에만 출석이 가능합니다.`

- 출석 수정
    - [] 닉네임, 수정 날짜, 등교 시간에 맞는 출석 기록 찾기
        - [] 등록되지 않은 닉네임을 입력한 경우 예외 반환 `[ERROR] 등록되지 않은 닉네임입니다.`
        - [] 주말 또는 공휴일인 경우 **오늘 날짜와 함께** 예외 반환 `[ERROR] 12월 14일 토요일은 등교일이 아닙니다.`
        - [] 미래 날짜로 출석 수정하는 경우 예외 반환 `[ERROR] 아직 수정할 수 없습니다.`
        - [] 등교 시간이 캠퍼스 운영 시간이 아닌 경우 예외 반환 `[ERROR] 캠퍼스 운영 시간에만 출석이 가능합니다.`

- 출석 기록 확인
    - [] 출석 판단
        - 월요일은 13:00~18:00, 화요일~금요일은 10:00~18:00
        - 주말 및 공휴일은 출석x
        - 해당 요일의 시작 시각으로부터 5분 초과 시 지각 처리
        - 해당 요일의 시작 시각으로부터 30분 초과 시 결석 처리
        - 등교하지 않아 출석 기록이 없는 날은 결석 처리
    - [] 출석, 지각, 결석 횟수 세기

- 제적 위험자 판단하기
    - [] 결석, 지각 횟수 세기
    - [] 경고 | 면담 | 제적 판단하기
        - 지각 3회는 결석 1회로 간주
        - 경고 대상자: 결석 2회 이상
        - 면담 대상자: 결석 3회 이상
        - 제적 대상자: 결석 5회 초과

## 출력 기능

- 출석 확인
    - [] 출석 현황 출력 `12월 13일 금요일 09:59 (출석)`
- 출석 수정
    - [] 출석 현황 출력 `12월 03일 화요일 10:07 (지각) -> 09:58 (출석) 수정 완료!`
- 출석 기록
    - [] 출석 기록 출력
    - [] 출석 | 지각 | 결석 횟수 출력
    - [] 면담 대상자 여부 출력
    - ```text
  이번 달 빙티의 출석 기록입니다.

  12월 02일 월요일 13:00 (출석)
  12월 03일 화요일 09:58 (출석)
  12월 04일 수요일 10:02 (출석)
  12월 05일 목요일 10:06 (지각)
  12월 06일 금요일 10:01 (출석)
  12월 09일 월요일 --:-- (결석)
  12월 10일 화요일 10:08 (지각)
  12월 11일 수요일 --:-- (결석)
  12월 12일 목요일 --:-- (결석)

  출석: 4회
  지각: 2회
  결석: 3회

  면담 대상자입니다.
    ```
- [] 제적 위험자 출력
    - 제적 대상자, 면담 대상자, 경고 대상자순으로 출력
    - 지각을 결석으로 간주하여 내림차순한
    - 출석 상태가 같으면 닉네임으로 오름차순 정렬

```text
- 빙티: 결석 3회, 지각 2회 (면담)
- 이든: 결석 2회, 지각 4회 (면담)
- 쿠키: 결석 2회, 지각 2회 (경고)
- 빙봉: 결석 1회, 지각 5회 (경고)
```

- [] 예외 메세지 출력
    - `[ERROR]` 로 시작할 것

## 요구 사항

- 프로그램은 사용자가 종료할 때까지 종료되지 않으며, 해당 기능을 수행한 후 초기 화면으로 돌아간다.
- 사용자가 잘못된 값을 입력할 경우 "[ERROR]"로 시작하는 메시지와 함께 IllegalArgumentException을 발생시킨 후 애플리케이션은 종료되어야 한다.
- 캠퍼스 운영 시간은 매일 08:00~23:00이다.
- 현재 날짜와 시간을 가져오려면 camp.nextstep.edu.missionutils.DateTimes의 now()를 활용한다.
- 사용자가 입력하는 값은 camp.nextstep.edu.missionutils.Console의 readLine()을 활용한다.
