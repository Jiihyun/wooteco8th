# 기능 목록

## 입력 기능

- [x] 코치 이름 입력(, 로 구분해서 입력)
    - [x] 공백일 경우 예외 발생시키기
    - [x] 잘못된 형식일 경우 예외 발생시키기
    - [] 잘못된 입력 재입력 처리하기
- [] 각 코치마다 못 먹는 메뉴 입력받기(, 로 구분해서 입력)
    - [] 잘못된 형식일 경우 예외 발생시키기
    - [] 잘못된 입력 재입력 처리하기

## 비지니스 기능

- [] 코치 등록하기
    - 코치 이름
        - [] 최소 2글자 ~ 최대 4글자 | 이외 범위 예외 발생
    - 못 먹는 메뉴
        - [] 최소 0개 ~ 최대 2개 | 이외 범위 예외 발생
        - [] 등록된 메뉴 외 메뉴 등록 시 예외 발생
        - [] 중복된 메뉴 등록 시 예외 발생
    - 코치 총 인원
        - [] 최소 2명 ~ 최대 5명 | 이외 범위 예외 발생

- [] 메뉴 추천하기
    - [] 각 요일에 추천할 카테고리를 무작위로 정한다.
    - [] 각 코치가 각 요일에 먹을 메뉴를 추첨한다.
    - [] 추천할 수 없는 메뉴일 시 다시 추첨하기
    - 고려 사항
        - [] 한 주에 같은 카테고리는 최대 2회까지만 가능
        - [] 한 주에 같은 메뉴가 중복되면 안됨

## 출력 기능

- [x] 서비스 시작 문구 출력하기 `점심 메뉴 추천을 시작합니다.`
- [] 메뉴 추천 결과 출력하기

```text
메뉴 추천 결과입니다.
[ 구분 | 월요일 | 화요일 | 수요일 | 목요일 | 금요일 ]
[ 카테고리 | 한식 | 한식 | 일식 | 중식 | 아시안 ]
[ 토미 | 쌈밥 | 김치찌개 | 미소시루 | 짜장면 | 팟타이 ]
[ 제임스 | 된장찌개 | 비빔밥 | 가츠동 | 토마토 달걀볶음 | 파인애플 볶음밥 ]
[ 포코 | 된장찌개 | 불고기 | 하이라이스 | 탕수육 | 나시고렝 ]

추천을 완료했습니다.
```

- [] 예외 메세지 출력
    - `[ERROR]` 로 시작할 것

## 요구 사항

- 추천할 카테고리는 `Randoms.pickNumberInRange()` 사용
  결과가 1이면 일식, 2면 한식, 3이면 중식, 4면 아시안, 5면 양식을 추천
  추천할 수 없는 카테고리인 경우 다시 Randoms.pickNumberInRange()를 통해 임의의 값을 생성해서
  추천할 카테고리를 정해야 한다.

```text
// 예시 코드. 사용하는 자료 구조에 따라 난수를 적절하게 가공해도 된다.
String category = categories.get(Randoms.pickNumberInRange(1, 5));
```

- 메뉴 추천 시 `Randoms.shuffle()` 사용
  카테고리에 포함되는 메뉴 목록을 List<String> 형태로 준비한다.

```text
String menu = Randoms.shuffle(menus).get(0);
```

- 임의로 메뉴의 순서 또는 데이터를 변경하면 안 된다.
  Randoms.shuffle() 메서드의 인자로 전달되는 메뉴 데이터는, 최초에 제공한 목록을 그대로 전달해야 한다.
  코치에게 추천할 메뉴를 정할 때 이미 추천한 메뉴, 먹지 못하는 메뉴도 포함된 리스트를 전달해야 한다.
  추천할 수 없는 메뉴인 경우 다시 섞은 후 첫 번째 값을 사용해야 한다.
