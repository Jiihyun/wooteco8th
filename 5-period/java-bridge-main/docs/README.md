# 기능 목록

## 입력 기능

- [x] 다리 길이 입력
    - [x] 숫자 아닐 경우 예외 발생시키기
    - [x] 공백일 경우 예외 발생시키기
    - [x] 예외 후 재입력 처리

- [x] 이동할 칸 입력 `U(위 칸)와 D(아래 칸)`
    - [x] 공백일 경우 예외 발생시키기
    - [x] 예외 후 재입력 처리

- [x] 게임 재시도 여부 입력 `R(재시작)과 Q(종료)`
    - [x] 공백일 경우 예외 발생시키기
    - [x] 예외 후 재입력 처리

## 비지니스 기능

- [x] 다리 길이에 맞는 다리 생성하기
    - [x] 다리 길이 조건: 3 이상 20 이하 `[ERROR] 다리 길이는 3부터 20 사이의 숫자여야 합니다.`
    - [x] 무작위 값이 0인 경우 아래 칸, 1인 경우 위 칸
- [x] 유저 다리 이동 하기
- [x] 게임 종료 조건 판단하기
    - 다리를 끝까지 건너면 게임 종료
- [x] 게임 재시도 조건 판단하기
    - 다리 건너다 실패했는지 판단
    - 재시도해도 처음에 만든 다리 재사용
- [x] 게임 총 시도 횟수 계산
    - 첫 시도를 포함해 게임을 종료할 때까지 시도한 횟수

## 출력 기능

- [x] 다리 이동 결과 출력하기
- [x] 최종 게임 결과 출력하기
    - 다리 이동 결과 출력
    - 게임 성공 여부 및 시도 횟수 출력
- [x] 예외 메세지 출력
    - `[ERROR]` 로 시작할 것
