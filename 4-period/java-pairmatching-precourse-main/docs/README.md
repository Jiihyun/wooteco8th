# 기능 목록

## 입력 기능

- [] 페어 매칭에 필요한 크루들 이름이 있는 파일 입력 `src/main/resources/backend-crew.md`

- [x] 기능 명령어 입력
    - [x] 공백일 경우 예외 발생시키기
    - [x] 존재하지 않는 명령어 예외 발생시키기
    - [] 잘못된 입력 재입력 처리하기

- [] 과정, 레벨, 미션 입력
    - [] 공백일 경우 예외 발생시키기
    - [] 존재하지 않는 과정, 레벨, 미션 예외 발생시키기
    - [] 잘못된 입력 재입력 처리하기

- [] 매칭 정보 이미 있을 때, 재매치 여부 입력
    - [] 공백일 경우 예외 발생시키기
    - [] 존재하지 않는 명령어 예외 발생시키기
    - [] 잘못된 입력 재입력 처리하기

## 비지니스 기능

- [] 파일에 있는 크루들 이름 저장하기

- [] 존재하는 과정, 미션, 레벨 등록하기

- 페어 매칭 하기
    - [] 기본 2명, 홀수인 경우 3명 구성
        - 랜덤으로 섞인 페어 목록에서 페어 매칭을 할 때 앞에서부터 순서대로 두명씩 페어를 맺는다.
        - 홀수인 경우 마지막 남은 크루는 마지막 페어에 포함시킨다.
    - [] 매칭 3번 시도 가능, 3회 초과시 예외 발생
        - 재매칭 조건: 같은 레벨에서 페어 중복일 경우 재매칭
    - [] 매칭 정보 존재 여부 파악하기(같은 조건으로 매칭 요청했나 파악 위함)
- 페어 조회 하기
    - [] 과정, 레벨, 미션이 같은 페어 조회하기
        - 존재하지 않으면 예외 발생`[ERROR] 매칭 이력이 없습니다.`

## 출력 기능

- [] 페어매칭 결과 출력
    - shuffle 메서드의 결과 순서로 정렬
    - ```text
  페어 매칭 결과입니다.
  용팔 : 대만
  대협 : 덕규
  치수 : 준호
  태웅 : 백호
  달재 : 태산
  한나 : 수겸
  태섭 : 대남
  준섭 : 소연
  현준 : 호열
  구식 : 경태
    ```
- [] 페어 초기화 결과 출력 `초기화 되었습니다.`
- [] 예외 메세지 출력
    - `[ERROR]` 로 시작할 것
