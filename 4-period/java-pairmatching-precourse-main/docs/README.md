# 기능 목록

## 입력 기능

- [x] 크루들 이름 파일 읽어오기
- [x] 기능 선택 입력
    - [x] 공백일 경우 예외 발생시키기
    - [x] 존재하지 않는 기능 명령어인 경우 예외 발생시키기
    - [] 잘못된 입력 재입력 처리하기
- [x] 과정, 레벨, 미션을 입력 `프론트엔드, 레벨1, 자동차경주`
    - [x] 공백일 경우 예외 발생시키기
    - [x] 존재하지 않는 과정, 레벨, 미션인 경우 예외 발생시키기
    - [] 잘못된 입력 재입력 처리하기
- [] 매칭 정보가 존재하는 경우, 재매칭 여부 입력
    - [] 존재하지 않는 기능 명령어인 경우 예외 발생시키기
    - [] 잘못된 입력 재입력 처리하기
    ```
    매칭 정보가 있습니다. 다시 매칭하시겠습니까?
    네 | 아니오
    ``` 

## 비지니스 기능

- [] 페어 매칭하기
    - [x] 짝수: 두명씩 매칭, 홀수: 두명씩 매칭 & 한 페어만 3인으로 구성(마지막 페어에 포함)
    - [x] 같은 레벨에서 페어한 경우, 다시 매칭될 수 없음
        - 다시 페어로 매칭 된다면 크루 목록의 순서를 다시 랜덤으로 섞어서 매칭 시도
        - 3회 시도까지 매칭이 되지 않거나 매칭을 할 수 있는 경우의 수가 없으면 예외 발생
- [] 페어 조회하기
    - [] 과정, 레벨, 미션에 따른 해당 미션의 페어 정보 조회
    - [] 매칭 이력이 없을 경우 예외 발생 `[ERROR] 매칭 이력이 없습니다.`
- [] 페어 초기화하기
    - 페어 매칭 결과를 초기화한다

## 출력 기능

- [x] 페어 매칭 결과 출력
    - 페어 순서는 camp.nextstep.edu.missionutils.Randoms의 shuffle 메서드의 결과 순서로 정렬
    ```text
    페어 매칭 결과입니다.
    다비 : 신디
    쉐리 : 덴버
    제키 : 로드
    라라 : 윌터
    니콜 : 이브
    린다 : 시저
    보노 : 제시 : 제키
    ```
- [] 페어 조회 결과 출력
- [] 페어 초기화 결과 출력 `초기화 되었습니다.`

- [] 예외 메세지 출력
    - `[ERROR]` 로 시작할 것
