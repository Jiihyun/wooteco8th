# 기능 목록

## 입력 기능

- [x] 자판기가 보유하고 있는 금액 입력
    - [x] 숫자 아닐 경우 예외 발생시키기
    - [x] 공백일 경우 예외 발생시키기
- [x] 상품명, 가격, 수량 입력받기 `[콜라,1500,20];[사이다,1000,10]`
    - [x] 공백일 경우 예외 발생시키기
- [x] 투입 금액 입력하기
    - [x] 공백일 경우 예외 발생시키기
- [x] 구매할 상품 입력하기
    - [x] 공백일 경우 예외 발생시키기

## 비지니스 기능

- [x] 자판기 보유 금액을 통해 동전 무작위 생성하기
    - [x] 자판기 보유 금액 범위 최소 100 ~ 최대 100_000
- [x] 상품 등록하기
    - 등록 수량
        - [] 최소 1개 ~ 최대 20개
    - 등록 가격
        - [x] 100원 이상이 아니면 예외 발생
        - [x] 10원으로 나누어 떨어지지 않으면 예외 발생
- [x] 상품 구매하기
    - 상품명 검증
        - [x] 등록된 상품이 아니면 예외 발생
    - [x] 상품 가격만큼 투입 금액 차감하기
    - [x] 상품 개수 차감하기
- 잔돈 반환하기
    - [x] 남은 투입 금액이 상품의 최저 가격보다 적거나, 모든 상품이 소진됐는지 판단하기
    - [x] 현재 보유한 최소 개수의 동전 개수 계산하기

## 출력 기능

- [x] 자판기가 보유한 동전 출력하기
- [] 잔돈 출력
    - 반환된 동전만 출력
- [] 예외 메세지 출력
    - `[ERROR]` 로 시작할 것

## 실행 예시

```

450

자판기가 보유한 동전
500원 - 0개
100원 - 4개
50원 - 1개
10원 - 0개

상품명과 가격, 수량을 입력해 주세요.
[콜라,1500,20];[사이다,1000,10]

투입 금액을 입력해 주세요.
3000

투입 금액: 3000원
구매할 상품명을 입력해 주세요.
콜라

투입 금액: 1500원
구매할 상품명을 입력해 주세요.
사이다

투입 금액: 500원
잔돈
100원 - 4개
50원 - 1개
```
