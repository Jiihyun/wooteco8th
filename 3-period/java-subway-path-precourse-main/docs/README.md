# 기능 목록

## 입력 기능

- [x] 기능 명령어 입력
    - [x] 공백일 경우 예외 발생시키기
    - [x] 잘못된 형식일 경우 예외 발생시키기
    - [x] 잘못된 입력 재입력 처리하기
- [x] 경로 기준 선택하기
    - [x] 공백일 경우 예외 발생시키기
    - [x] 잘못된 형식일 경우 예외 발생시키기
    - [x] 잘못된 입력 재입력 처리하기
- [x] 출발역 입력
    - [x] 공백일 경우 예외 발생시키기
    - [x] 잘못된 입력 재입력 처리하기
- [x] 도착역 입력
    - [x] 공백일 경우 예외 발생시키기
    - [x] 잘못된 입력 재입력 처리하기

## 비지니스 기능

- [x]  역, 노선, 구간 정보 등록
- [x] 경로 조회
    - 총 거리, 총 소요 시간 구하기
        - [x] 출발역과 도착역 같으면 예외 발생
        - [x] 출발역과 도착역 연결되어 있지 않으면 예외 발생
        - [x] 출발역과 도착역이 존재하지 않으면 예외 발생
    - 조회 기준: 최단 거리 & 최소 시간

## 출력 기능

- [x] 조회 결과(총 거리, 총 소요 시간, 거친 역들) 출력
    ```
      ## 조회 결과
    
    [INFO] ---
    [INFO] 총 거리: 4km
    [INFO] 총 소요 시간: 11분
    [INFO] ---
    [INFO] 교대역
    [INFO] 강남역
    [INFO] 양재역
    ```

- [x] 예외 메세지 출력
    - `[ERROR]` 로 시작할 것
