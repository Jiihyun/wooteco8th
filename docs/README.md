# 기능 목록

## 입력 기능

- [x] 월(숫자)과 시작 요일(일, 월, 화, 수, 목, 금, 토) 정보 입력
    - [x] 공백일 경우 예외 발생시키기
    - [x] 월이 숫자 아닐 경우 예외 발생시키기
    - [x] 존재하지 않는 요일인 경우 예외 발생시키기
    - [] 잘못된 입력 재입력 처리하기
- [x] 평일 비상 근무 순서 입력
    - [x] 공백일 경우 예외 발생시키기
    - [x] 잘못된 형식일 경우 예외 발생시키기
    - [] 잘못된 입력 재입력 처리하기
- [x] 휴일 비상 근무 순서 입력
    - [x] 공백일 경우 예외 발생시키기
    - [x] 잘못된 형식일 경우 예외 발생시키기
    - [] 잘못된 입력 평일 순번 부터 재입력 처리하기

## 비지니스 기능

- 사원 등록
    - 닉네임
        - [x] 최소 1자 ~ 최대 5자
- 비상 근무표 생성하기
    - [x] 평일 & 휴일(토,일,법정공휴일) 순번 생성
        - [x] 평일 순번, 휴일 순번에 각각 1회 편성, 이외의 경우 예외 발생
            - 평일 순번&휴일 순번 사이즈가 같아야 함
            - 순번 내에서 근무 2번 이상 금지
        - [x] 최소 5명 ~ 최대 35명
    - [] 연속 2일 근무 금지
        - 특정 근무자가 연속 2일 근무하게 되는 상황에는, 다음 근무자와 순서를 바꿔 편성

- 연도는 고려하지 않으며, 매년 2월은 28일까지만 있다고 가정한다.
- 비상 근무자 배정 시 다음 근무자와 순서를 바꿔야 하는 경우에는, 앞의 날짜부터 순서를 변경해야 한다.

## 출력 기능

- [] 비상 근무표 출력
    - 달, 일, 요일, 평일이면서 법정공휴일 여부, 닉네임
    - 평일이면서 법정공휴일의 경우에만 요일 뒤에 (휴일) 표기
- [] 예외 메세지 출력
    - `[ERROR]` 로 시작할 것

## 실행 예시

```
비상 근무를 배정할 월과 시작 요일을 입력하세요> 5,월
평일 비상 근무 순번대로 사원 닉네임을 입력하세요> 준팍,도밥,고니,수아,루루,글로,솔로스타,우코,슬링키,참새,도리
휴일 비상 근무 순번대로 사원 닉네임을 입력하세요> 수아,루루,글로,솔로스타,우코,슬링키,참새,도리,준팍,도밥,고니

5월 1일 월 준팍
5월 2일 화 도밥
5월 3일 수 고니
5월 4일 목 수아
5월 5일 금(휴일) 루루
...
5월 31일 수 도리
```
